# 使用说明

WinBootVideo 包含登录视频和开机静态 Logo，两者独立设置与恢复。初次打开不会改变系统启动配置。软件左下角也能打开离线说明。

## 运行环境

Windows 11 x64、.NET Framework 4.8 系列和 **x64 .NET 8 Desktop Runtime**。Windows 11 通常已包含 Framework；GUI 提示运行时缺失时，安装 [微软 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)，单独的 .NET Runtime 不含 WPF。

解压下载包后运行 `WinBootVideo.exe`，保留同目录全部文件。这是依赖运行时的便携版，不是单文件程序。FFmpeg / ffprobe 只用于视频检查与转码，软件不下载或分发它们。Logo 图片转换无需额外工具。

## 登录动画

1. 首页选择“登录动画”，选择或拖入本地视频。可以先用包内 `demo-login.mp4` 测试。
2. 点击“检查格式”。缺少工具时可直接预览，或选择同时含 `ffmpeg.exe`、`ffprobe.exe` 的目录。
3. 如需转换，展开转换工具，设置保留的前几秒，保存为新文件。原视频不覆盖。
4. 下一步选择屏幕、音量；淡出和等待上限在高级设置中。
5. 进入“预览与启用”，点击“保存并全屏预览”。Esc / 空格可跳过。播放至少前进 100 毫秒后，正常结束或跳过才算成功；加载失败、损坏或超时不会解锁启用按钮。
6. 确认效果后点击“启用登录动画”。它备份并设置当前用户的登录 Shell，不保存密码；下次注销或重启后登录生效，锁屏解锁不重复。
7. “恢复普通登录”恢复原 Shell 值，并按归属还原旧版的备用任务。恢复后下次登录生效。

点击保存预览时，视频复制到 `%LOCALAPPDATA%\WinBootVideo\media`。保存并成功预览、启用后可删除原视频或转码另存的文件。只选择视频尚未保存时，先保留原文件。

重新保存预览会暂停已有登录动画；验证新视频后需要再次启用。单纯选取或转换不会修改已保存的动画。旧版已启用时，“修复登录启动”迁移到桌面前模式，移除本工具自己的备用播放任务。

### 视频要求

| 项目 | 推荐 | 内置转换行为 |
| --- | --- | --- |
| 容器 / 编码 | MP4、H.264 / AVC | libx264 转码 |
| 像素 / 色彩 | 8 位 yuv420p、SDR | HDR PQ / HLG 色调映射到 SDR |
| 分辨率 / 帧率 | 1920×1080、30 fps | 保留比例、补黑边、转为 30 fps |
| 时长 | 5–15 秒 | 从开头保留指定长度，无时间轴编辑 |
| 音轨 | AAC 双声道或无音轨 | AAC / 48 kHz / 双声道，或移除 |
| 衔接 | 黑色首帧，尾帧接近壁纸 | 保留结束画面，整体淡出到桌面 |

推荐格式不能代替成功预览。播放器依赖 Windows / WPF 媒体组件，不自带 mpv 或 VLC；HEVC、AV1、10 位、HDR、透明视频或特殊封装建议转换。不同屏幕比例保留视频比例，以黑底显示；可遮住副屏，视频仅在选定屏幕播放，显示器拔除后回退到主屏。

接受本地非空视频，最大 2 GB，不接受网络路径 / 网络盘。播放上限 5–90 秒，默认 45 秒，从输入桌面激活、请求播放起计算，包括加载、播放、桌面等待和淡出。加载等待 2–15 秒，默认 8 秒；可见后仍有独立 30 秒冷启动上限。输入密码时不消耗播放预算，但未播放前等待超过 15 分钟会跳过本次动画。这条长时间等待路径仍有未解决诊断，见 [QA.md](../QA.md)。

视频太长会超时，建议先截短；转换长度上限 80 秒。HDR 转换要求 FFmpeg 构建包含 `zscale`、`tonemap`。外部工具许可取决于其构建，见 [FFmpeg 许可说明](https://ffmpeg.org/legal.html)。

### 登录后没有桌面怎么办

1. 先按 Esc / 空格跳过，或等待默认 45 秒；宿主会尝试放行 Explorer。
2. 仍无桌面时按 `Ctrl+Shift+Esc`，必要时 `Ctrl+Alt+Del` → 任务管理器。
3. “运行新任务”执行 `explorer.exe`，先进入桌面。
4. 执行 `%LOCALAPPDATA%\WinBootVideo\恢复普通登录.cmd`，它使用 Framework 宿主恢复，即使 .NET 8 GUI 无法运行也可使用。

也可执行以下命令，将路径改为当前用户的真实路径：

```text
"C:\Users\你的用户名\AppData\Local\WinBootVideo\app\WinBootVideo.Host.exe" --restore --data-dir "C:\Users\你的用户名\AppData\Local\WinBootVideo"
```

备份为 `shell-backup.json` 和 `login-task-backup.json`。若宿主或备份被删除，任务管理器运行 `regedit.exe`，检查 **HKCU** 的 `Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell`。只有值仍是 WinBootVideo 命令时才按原备份恢复；原备份 `exists: false` 表示删除这个 Shell 值，不能删除整个 Winlogon 键，也不要改 HKLM。原本有其他值时必须还原原文本和类型。旧任务也只在命令仍属于本应用时处理。

## 开机 Logo

功能改变的是 Windows 加载阶段的静态 BGRT 图片，包括此阶段的七彩虹等厂商 Logo。刚通电时固件显示的第一张图片仍可能出现；软件不刷写或修改 BIOS，也不更改 Windows 转圈动画、锁屏或登录背景。

### 检查与准备

1. 进入“开机 Logo”，执行管理员只读检查。它不安装、不改变启动顺序。
2. 当前支持 UEFI x64、单 Windows 启动器、单 EFI 系统分区且与系统位于同一磁盘、系统盘完全未加密、至少 20 MB EFI 空间。经完整核验的 Insyde 通用 USB / 光驱 / 网络入口保留。其他系统、未知项、多 EFI 分区、待执行 BootNext 或无法核实的状态停止安装。
3. 备好可启动的 Windows 恢复 U 盘、可用的帐户密码（不要只依赖 PIN），将恢复说明另存到手机或其他设备，查好电脑官方的 Boot Menu 入口。
4. 保持现有 Secure Boot、TPM、UEFI / CSM、SATA 设置。不需预先关闭安全启动、挂载 EFI 或分配盘符；不要清空密钥、解密系统盘、格式化分区或删除启动项来绕过检查。
5. 选择图片，软件自动转换；导出准备包，然后完成恢复、试启动和必要的 shim 确认。

安装条件会列出所有未满足项。检查有效期为十分钟，安装前重新核验；取消 UAC 后需重查。额外启动项不一定代表双系统，也可能是厂商功能。“启动项详情”给出编号、路径和结构信息，名称相同不代表安全。没有“强制安装”入口。

### 图片要求

| 项目 | 要求或处理 |
| --- | --- |
| 输入 | 本地静态 PNG / JPEG / BMP；最多 16 MB、2000 万像素、每边最多 8192 |
| 推荐画布 | 320×180 或 256×256，最大 600×360，图案居中、黑底 |
| 转换 | 保留比例缩放，透明区域合成黑色，补黑边 |
| 输出 | 24 位未压缩 BMP3，54 字节头、正向高度、四字节行对齐 |
| 显示 | 保留固件分辨率，居中偏上；桌面预览只是示意 |

### 导出准备包

准备包是安装前保存的材料文件夹，不是 Windows 恢复 U 盘，也不是本机启动备份。它包含处理后的 `splash.bmp`、`config.txt`、官方 HackBGRT 工具、安装器本地路径兼容配置、许可证和首次启动 / 恢复说明。

**当前版本必须先导出才能安装**，安装使用包内已校验的 `splash.bmp`；管理员辅助进程另外从内置的固定官方包重新校验、解包工具。不能靠替换准备包中的工具绕过校验，也不要手动运行原版安装器的覆盖 Windows 启动器选项。

不导出时可以检查、选图和看预览，但不能继续安装。导出后尚未安装时没有开机效果变化，可以删除原图，但需保留准备包；若删包、改图或重新选图，重新导出即可。导出是一项本地文件操作，不修改 EFI、NVRAM、BCD 或 BIOS。

恢复说明可另存到另一设备；**本机原启动记录是在管理员安装时才创建的**，保存在 `%ProgramData%\WinBootVideo-BootLogo`。导出的包不包含这些记录。

### 安装

安装先保存原始启动顺序、启动项和 Windows 启动器备份，再调用 HackBGRT 的仅安装文件入口。六个 EFI 文件和图片通过核验后才创建独立启动项，追加到启动顺序末尾。Windows Boot Manager 仍默认，原 Windows 启动器不覆盖。失败时尝试撤销自身变更，撤销不完整会报告并保留记录。

看到“安装并读回核验完成”表示文件与独立项安装完成，**不代表普通重启就会显示新 Logo**。已安装后只需重新只读检查，无需重复安装。更换图片先恢复原 Logo，再重新准备和安装。

### 首次启动与每次生效

下面的流程已收到一台 Windows 11 / COLORFUL P15 23 / Insyde UEFI 实机反馈，环境为 Secure Boot 开启、未加密系统盘、单 EFI 分区；其他设备仍需自行试启动。

1. 保存工作，进入固件 Boot Menu / Boot Manager，单次选择 **HackBGRT**。按键见电脑官方手册。也可从 Windows“设置 → 系统 → 恢复 → 高级启动 → 疑难解答 → 高级选项 → UEFI 固件设置”手动进入固件。
2. Secure Boot 开启时，若出现 `Verification failed / 0x1A` 蓝色提示，选择 `OK` 并按 Enter。
3. 接下来的 **5 秒倒计时内按任意键**进入 MOKManager；错过则重新试启动。
4. 选择 `Enroll hash from disk` → 系统盘 → `EFI → HackBGRT → grubx64.efi`。
5. 选择 `Continue → Yes → Reboot`，确认该文件的哈希。保持 Secure Boot 开启，不选择 `Enroll key from disk` 或信任整张证书，不清空 TPM。
6. 重启后再次单次选择 HackBGRT，确认自定义 Logo 显示并能正常登录 Windows。没有 MOKManager 或无法继续时，回到 Windows Boot Manager 并停止，不先设为默认。
7. 验证成功后，在 BIOS 的 `Boot Priority / Boot Order` 中将 HackBGRT 放到第一位，保留 Windows Boot Manager 及其他设备项，按固件界面提示保存退出。
8. 验证正常重启和关机后开机。软件重新检查会分别显示“已安装”和“已设为默认”；单次选择不会被当成默认已保存。

Logo 已存在 EFI，不需软件常驻或每次重装。当前软件提供指引，没有一键修改默认顺序。固件更新或恢复默认后原 Logo 再出现时，先检查启动顺序。Windows 快速启动可能影响关机再开机的表现，软件不自动修改它。

官方 [shim 说明](https://github.com/Metabolix/HackBGRT/blob/v2.6.0/shim.md)和[微软固件入口说明](https://support.microsoft.com/en-us/windows/security/devicesecurity/windows-11-and-secure-boot)可供核对。启动链变化可能影响 Windows Hello / PIN 或依赖 TPM 的反作弊，未验证所有游戏；PIN 不可用时用帐户密码登录并恢复，不清空 TPM。

### Logo 恢复

试启动失败或卡住时，从固件菜单选择 Windows Boot Manager。曾改过默认顺序的先将它调回第一位，再进入 Windows 点击“恢复原 Logo”。自动恢复先核验受保护记录和当前项，只移除有归属凭据的自身启动项引用和启动项，不整体导入旧 BCD 或覆盖当前 Windows。

EFI 中的 Logo 文件保留，以免固件残留引用指向已删除文件。记录缺失、损坏、外来项或文件变化时停止自动恢复，应保留操作详情核对原因。不能拿其他电脑的准备包或恢复记录来还原本机启动状态。

## 文件保留与删除

| 文件 / 目录 | 什么时候可以删除 |
| --- | --- |
| 原视频、转码另存的视频 | 成功保存预览后有应用内副本；启用前再确认预览结果 |
| 原 Logo 图片 | 导出准备包后有独立图片副本 |
| Logo 准备包 | 安装且单次试启动成功后可以删除；先另存恢复说明 |
| `%LOCALAPPDATA%\WinBootVideo` | 登录动画启用期间保留，含程序、媒体、配置和恢复备份 |
| `%ProgramData%\WinBootVideo-BootLogo` | 保留到完成 Logo 恢复；这是本机原启动状态记录 |
| 下载的程序 ZIP / 解压目录 | 登录动画安装到 AppData 后可留作备用；删除不会清除已安装的 EFI Logo，但保留一份软件便于恢复 |

卸载前分别恢复已启用的功能，确认下一次登录 / 启动正常，再清理相应应用数据。不要仅删除程序以代替恢复。

## 故障报告

先保存版本、完整错误文本和复现步骤。登录日志在 `%LOCALAPPDATA%\WinBootVideo\logs`；Logo 页面有“操作详情”和只读启动项报告。上传前检查个人路径、用户名和设备信息，不上传个人视频、密码、恢复密钥或整个恢复目录。已知范围见 [QA.md](../QA.md)。
